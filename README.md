# Unit Converter with Navigation

A Flutter app with a home menu and one reusable conversion screen for length, weight, and temperature. Length and weight use conversion factors; temperature uses dedicated formulas. Invalid input is reported without crashing.

## Run in DartPad

Open [DartPad](https://dartpad.dev/), choose Flutter, paste `lib/main.dart`, then select **Run**.

## Run locally

Install Flutter, then run `flutter pub get` and `flutter run` from this folder.

## Checklist walkthrough

Open each category, convert length and weight values, try Celsius to Fahrenheit, and use Back to return home. Clear the input and confirm the inline hint. The same `ConverterPage` is configured with different unit data for all categories.
